# История сообщества — интерактивный сайт

Откройте `index.html` в современном браузере.

## Что внутри
- Древо истории с главами и ветками.
- Полный текст, перенесённый из `История сервера.docx`.
- Поиск по названиям и содержанию.
- Добавление нескольких изображений к каждому пункту.
- Сохранение изображений в IndexedDB браузера — без сервера.
- Удаление изображений, открытие в полном размере и печать выбранного пункта.
- Адаптация под телефон.

Важно: изображения хранятся локально в конкретном браузере/профиле и не загружаются в интернет.


## Изображения участников
В файле `people-data.js` в конце находится объект `window.PEOPLE_IMAGE_URLS`. Вставьте прямую ссылку на изображение в кавычки напротив каждого ID. Например: `"pasha2911": "https://example.com/photo.jpg"`. У каждого из 14 участников своя отдельная настройка. Для прямых ссылок лучше использовать URL, который открывает сам файл изображения.
